# Tactula firmware downloads

Official Tactula firmware binaries are distributed through [GitHub Releases](https://github.com/MrSleeps/tactula/releases), not by downloading or building release-tooling files.

Choose the matching JC3248W535 Standard or With Bambu edition, then use the appropriate full USB-install or OTA-update image. See the [installation guide](../GUIDE.md#installing-tactula-firmware), [firmware editions](../FIRMWARE_VARIANTS.md) and [automatic update instructions](../GUIDE.md#automatic-firmware-updates).
